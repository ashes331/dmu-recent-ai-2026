## 이 실행에서 특히 짚을 만한 것

**① "기억해 가지고 있습니다"라고 답해 놓고 바로 다음 호출에서 모릅니다**

1차 응답은 확답에 이모지까지 붙습니다. 그런데 2차는 완전히 새 호출이라 그 약속이 남아 있지 않습니다.
**약속을 지키지 못하는 게 아니라, 약속한 사실 자체가 존재하지 않습니다.**

**② 모른다고 하지 않고 "알렉스"라는 이름을 지어냅니다 ★**

이번 실행의 핵심입니다. 4b 실측(2026-08-21)은 *"제 이름은 Gemma입니다"* 로 **질문을 잘못 알아듣는** 형태였는데,
1b는 **없던 이름을 자신 있게 단언**합니다.

```
2차 응답 : 당신의 이름은 "알렉스"라고 하셨습니다. 😄
```

`"~라고 하셨습니다"` 라는 표현까지 붙어 있습니다. **하지도 않은 말을 했다고 인용하는 것**입니다.
실패 ②(기억 없음)와 실패 ①(지어냄)이 한 문장에서 겹치는 장면이라 수업에서 짚기 좋습니다.

**③ [B]에서는 정말로 이름을 맞힙니다**

같은 모델·같은 질문인데 [B]는 맞힙니다. 우리가 이력을 다시 보냈기 때문입니다.
작년 Streamlit 챗봇이 대화가 이어진 것처럼 보였던 이유가 바로 이것(`session_state`)이라는 연결로 이어집니다.

> 참고: [B] 응답의 *"당신은 이름은 이재숙이 맞습니다"* 는 조사가 어색합니다. 1b의 한국어 품질 한계이고,
> 이 절의 논지(이력을 보내면 맞힌다)에는 영향이 없습니다.

## 학생 PC(4b)에서 다르게 나오는 부분

**[A]의 2차 응답 내용은 실행할 때마다, 모델마다 달라집니다.** 지어내는 이름이 다르거나,
*"알려주신 적이 없습니다"* 처럼 정직하게 답할 수도 있습니다.

**바뀌지 않는 것은 `[A] 아니오 / [B] 예` 라는 구조**입니다. 스크립트가 이 판정을 자동 출력하므로
학생 화면의 문장이 슬라이드와 달라도 결론은 그대로 확인됩니다.

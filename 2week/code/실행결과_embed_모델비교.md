### 실습 3 — 검색 순위 (질문: "졸업하려면 몇 학점 들어야 해?")

| 순위 | MiniLM (다국어) | KR-SBERT (한국어) |
|:---:|------|------|
| **1위** | 0.4701 · 문서4 캡스톤디자인 **❌ 오답** | 0.4948 · 문서0 이수 요건 **✅ 정답** |
| 2위 | 0.3689 · 문서0 이수 요건 *(정답이 밀림)* | 0.4771 · 문서1 전공필수 |
| 3위 | 0.3561 · 문서1 전공필수 | 0.4170 · 문서4 캡스톤디자인 |
| 4위 | 0.2370 · 문서2 학생 식당 | 0.2439 · 문서3 도서관 |
| 5위 | 0.2227 · 문서3 도서관 | 0.1511 · 문서2 학생 식당 |

### 세 실습 종합

| 항목 | MiniLM (다국어 384) | KR-SBERT (한국어 768) |
|------|------|------|
| 실습2 질문 vs 졸업요건 | 0.3689 | **0.4948** |
| 실습2 질문 vs 학식메뉴 | 0.2948 | 0.3006 |
| **실습2 격차** | **0.074** — 흐림 | **0.194** — 선명 (약 2.6배) |
| 실습3 1위 | ❌ 문서4 캡스톤 | ✅ 문서0 (정답) |

> "관련 있음"과 "관련 없음"을 거의 구분하지 못하는 상태이고, 그래서 실습 3에서 순위가 뒤집힙니다.

## 이 실행에서 특히 짚을 만한 것

**① 실습 4 "블록 안 평균"은 MiniLM이 더 높습니다 (0.689 > 0.624)**

숫자만 보면 MiniLM이 나아 보이지만 **잘못된 독법입니다.** 중요한 것은 절대값이 아니라
**블록 안과 블록 사이의 격차**입니다. MiniLM은 관련 없는 문장끼리도 0.419로 높게 나옵니다.
**전체를 다 비슷하다고 보는 것**이라, 히트맵에서 블록 구조가 흐려집니다.

> 수업에서 "유사도 숫자가 높은 모델이 좋은 모델"로 오해되기 쉬운 지점입니다. **격차를 보라**고 짚어 주십시오.

**② 차원(384 → 768)이 원인이 아닙니다**

| | MiniLM | KR-SBERT |
|---|---|---|
| 만든 방식 | 영어 SBERT를 teacher로 삼아 **50여 개 언어로 지식 증류** | 한국어 코퍼스 + **KLUE-NLI · KorSTS로 직접 학습** |
| 한국어의 위상 | 수십 개 언어 중 하나 | **학습 목표 그 자체** |
| 토크나이저 | 어휘를 여러 언어가 나눠 씀 → 한국어 조사·어미가 잘게 쪼개짐 | 한국어 어휘에 집중 |

차원이 커서 좋아진 것이 아니라, **한국어 문장 유사도 과제로 직접 학습했는지**가 갈랐습니다.
"차원이 크면 좋다"로 요약되지 않게 주의하십시오.

**③ 왜 하필 "캡스톤디자인"이 1위인지는 검증하지 않았습니다**

`이수`·`학년`·`학기` 같은 학사 어휘의 표면적 근접성 때문으로 **추정**되지만 확인한 바 없습니다.
**수업에서 단정하지 마십시오.** 짚어야 할 것은 원인이 아니라 **"오답이 1위로 올라온다"는 사실**입니다.

**④ 강의안의 예상 출력과 소수점 4자리까지 일치합니다**

KR-SBERT 순위(`0.4948 / 0.4771 / 0.4170 / 0.2439 / 0.1511`)가 강의안·배포본에 적힌 값과 완전히 같습니다.
**수업 중 학생 화면에도 같은 숫자가 나옵니다.**

## 재현 방법

아래 스크립트를 `code/` 에서 실행하면 위 출력이 그대로 나옵니다.

```python
import numpy as np
from sentence_transformers import SentenceTransformer

MODELS = [
    "paraphrase-multilingual-MiniLM-L12-v2",
    "snunlp/KR-SBERT-V40K-klueNLI-augSTS",
]

docs = [
    "본 학과의 이수 요건은 총 130학점이다.",
    "전공필수 과목은 반드시 수강해야 하며 재수강이 제한된다.",
    "학생 식당은 평일 오전 11시부터 오후 2시까지 운영한다.",
    "도서관은 시험 기간에 24시간 개방한다.",
    "캡스톤디자인은 4학년 1학기에 이수하는 것을 권장한다.",
]
query = "졸업하려면 몇 학점 들어야 해?"
sents = [query, docs[0], "오늘 학식 메뉴가 뭐야?"]
heat = ["졸업 이수 학점", "학위 취득 요건", "전공필수 과목", "학생 식당 운영 시간", "점심 메뉴 안내"]


def cos(a, b):
    return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))


for name in MODELS:
    print("=" * 68)
    print(name)
    print("=" * 68)
    m = SentenceTransformer(name)

    v = m.encode(sents)
    print(f"  [실습2] 차원 {v.shape[1]}")
    print(f"  [실습2] 질문 vs 졸업요건 : {cos(v[0], v[1]):.4f}")
    print(f"  [실습2] 질문 vs 학식메뉴 : {cos(v[0], v[2]):.4f}")

    q, d = m.encode(query), m.encode(docs)
    sc = sorted(((i, cos(q, x)) for i, x in enumerate(d)), key=lambda t: -t[1])
    print("  [실습3] 순위")
    for r, (i, s) in enumerate(sc, 1):
        print(f"          {r}위 {s:.4f} 문서{i} {docs[i][:28]}"
              f"{' (정답)' if i == 0 else ''}{'  <== 1위' if r == 1 else ''}")

    hv = m.encode(heat, normalize_embeddings=True)
    sim = hv @ hv.T
    ins = np.mean([sim[0, 1], sim[0, 2], sim[1, 2], sim[3, 4]])
    outs = np.mean([sim[i, j] for i in range(3) for j in (3, 4)])
    print(f"  [실습4] 블록 안 평균 {ins:.3f} / 블록 사이 평균 {outs:.3f}  → 격차 {ins - outs:.3f}")
    print()
```

> ⚠️ 두 모델을 **처음 실행하면 각각 400~500MB를 내려받습니다.** 수업 중에 돌리지 마십시오.

## 📌 이 문서를 남긴 이유

강의안·배포본·PPT 세 곳에 "다국어 모델이 오답을 1위로 올렸다"가 적혀 있지만,
**원본 실행 로그가 없어 근거를 다시 물었을 때 재현부터 해야 했습니다.**

`fail_01~03` 과 마찬가지로 **원문 출력을 보존**해, 다음에는 이 파일만 열면 되도록 했습니다.

> 📌 이 교체 사례 자체가 3교시 1-5절 **"한국어 지원이 모델 선택 기준인 이유"** 의 실제 근거입니다.
> **"다국어 지원"은 "그 언어를 잘한다"가 아니라 "입력을 받기는 한다"에 가깝습니다.**
> 반드시 **자기 데이터로 직접 재보고** 골라야 한다는 것이 이 실행의 결론입니다.

### 비용 계산

```
1회 비용   = (입력 토큰 × 입력 단가) + (출력 토큰 × 출력 단가)      ← 단가는 100만 토큰당
한 달 비용 = 1회 비용 × 하루 사용자 × 1인당 호출 × 30일
```

```powershell
python swap_models.py cost 입력토큰 출력토큰 하루사용자 1인당호출    # 모델을 부르지 않고 계산만
```

> 단가를 외우지 마십시오. 외울 것은 **계산 구조**입니다 — 입력과 출력의 단가가 다르고,
> **출력이 대체로 더 비싸서 출력 비중이 크다**는 점, 그리고 비용은 **1회가 아니라 곱하기로 본다**는 점.
